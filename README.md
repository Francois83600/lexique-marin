# Quiz Lexique marin

Application web pour apprendre le vocabulaire marin en français et en anglais britannique : 104 mots illustrés, quiz (mot anglais, mot français ou photo seule), un onglet Signaux (pavillons, flammes, balisage, feux de nuit, détresse, alphabet VHF), phrases en situation, mode À l'oreille, duel, carte du voyage, rappels de révision, classements semaine / défi du jour / mots / signaux / total, transfert de progression par code, mode hors connexion et interface en anglais.

Pour jouer : ouvrir le lien GitHub Pages du dépôt sur iPhone dans Safari, puis Partager > « Sur l'écran d'accueil ».

- `index.html` : l'application.
- `lexique.json` : les mots et leurs images.
- `firestore.rules` : règles de sécurité à coller dans Firebase (onglet Règles de Firestore).
- `i18n-en.js` : traduction anglaise de l'interface.
- `sw.js` : mode hors connexion (changer le numéro de `CACHE` à chaque mise à jour importante).

Photos : Wikipédia et Wikimedia Commons, chacune sous sa licence libre (crédits dans l'onglet Lexique de l'app). Dessins réalisés pour l'app.
